============================================================
  小说 → 角色卡生成器 · 便携版
============================================================

把小说文本自动转换成 SillyTavern 角色卡
（A 包世界书 + B 包酒馆助手预设，含时间线、事件压力、变量树）

全程在你自己的电脑上运行，除了调用你自己填的 AI 接口，
不会向任何其他地方发送数据。


------------------------------------------------------------
  一、怎么启动
------------------------------------------------------------

■ Windows

  1. 双击「启动.cmd」
  2. 如果弹出"Windows 已保护你的电脑"，点「更多信息」→「仍要运行」
  3. 等待浏览器自动打开（默认 http://localhost:3000）

■ macOS

  1. 第一次使用：右键点「启动.command」→「打开」→ 在弹窗里再点「打开」
     （直接双击会被系统拦住，因为脚本不是从 App Store 下载的）
     如果右键也打不开：打开「终端」，把「启动.command」拖进去，回车
  2. 以后直接双击即可
  3. 等待浏览器自动打开

■ Linux

  1. 第一次使用需要先加执行权限。打开终端，进入本文件夹后执行：
         chmod +x 启动.sh
  2. 然后运行：
         ./启动.sh
  3. 等待浏览器自动打开

  如果浏览器没自动打开，手动访问：http://localhost:3000


------------------------------------------------------------
  二、首次运行要等一会儿（重要）
------------------------------------------------------------

第一次启动时，程序需要联网下载它依赖的运行库：

  * 需要联网，通常 30 秒到 2 分钟
  * 窗口里会显示「首次运行：正在安装依赖」
  * 这期间请不要关闭窗口
  * 装完后会自动记住（生成 .deps-ok 标记文件）
  * 以后每次启动都是秒开，不会再装

看到「[OK] 依赖安装完成」和「正在启动服务...」就说明成功了。


------------------------------------------------------------
  三、开始使用
------------------------------------------------------------

浏览器打开后：

  1. 「设置」页填写
       Base URL：https://api.deepseek.com/v1
       API Key ：你自己的密钥
       模型名  ：deepseek-chat
     然后点「测试连接」确认可用

  2. 「生成流程」页
       - 选择小说文件（.txt / .md）
       - 选配图（可选，第一张会作为角色卡头像）
       - 选 user 角色模式（不确定就选「自动判定」）
       - 点「开始生成」

  3. 生成过程中可以随便切换页面，侧边栏会一直显示进度；
     回到「生成流程」页能看到完整的步骤与日志。

  4. 生成完成后到「任务与产物」页下载产物，
     按产物里的 README.md 导入 SillyTavern。


------------------------------------------------------------
  四、常见问题
------------------------------------------------------------

【1】提示 [ERROR] Node.js was not found / 未检测到 Node.js
    这台电脑还没装 Node.js。脚本会自动打开下载页：
        https://nodejs.org/
    请下载 LTS 版本安装，装完后重新运行启动脚本。
    （Windows 装的时候保持默认选项即可，会自动带 npm）

【2】提示 Node.js 版本过低
    需要 18 或更高版本。到 https://nodejs.org/ 下载最新 LTS 覆盖安装。

【3】依赖安装失败
    脚本会自动用国内镜像重试一次。如果还是失败，手动执行：
        npm config set registry https://registry.npmmirror.com
        npm install
    若提示 EACCES / 权限不足：
        Windows：用管理员身份运行「启动.cmd」
        macOS / Linux：在命令前加 sudo，或
            npm config set prefix ~/.npm-global

【4】端口 3000 被占用
    多半是上一次的生成器还在运行（找找有没有没关的黑窗口）。
    启动脚本会问你要不要换到 3001，按回车即可。
    也可以手动指定端口：
        Windows：      set PORT=3005 && npm start
        macOS / Linux：PORT=3005 npm start

【5】macOS 提示"无法打开，因为来自身份不明的开发者"
    右键点「启动.command」→「打开」→ 再点「打开」。
    只需要做一次。

【6】Linux 提示 Permission denied
    执行 chmod +x 启动.sh 后再运行。

【7】中文显示成乱码
    Windows：启动脚本已设置 chcp 65001，若仍乱码，
             请在"区域设置"里勾选「Beta: 使用 Unicode UTF-8 提供全球语言支持」。
    macOS / Linux：终端一般默认 UTF-8，无需处理。

【8】解压后中文文件名乱码
    用 7-Zip 或 WinRAR 解压，不要用系统自带的解压工具。

【9】浏览器没有自动打开
    手动访问 http://localhost:3000 即可，功能不受影响。


------------------------------------------------------------
  五、系统要求
------------------------------------------------------------

  * Node.js 18 或更高版本
  * 现代浏览器（Chrome / Edge / Firefox / Safari）
  * 能访问你选择的 AI 接口（国内推荐 DeepSeek，便宜好用）

  不需要：Python、数据库、任何编译工具


------------------------------------------------------------
  六、隐私说明
------------------------------------------------------------

  * 服务只监听本机（127.0.0.1），外部无法访问
  * API Key 只保存在你浏览器里，用完即走，不写进文件
  * 小说文本只在你的电脑和你填的 AI 接口之间传输
  * 生成结果保存在本文件夹的 output/ 目录，可随时删除
